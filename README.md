# Britta - Smart SRE Agent Landing Page

This project is a modern, dark-themed landing page for **Britta**, an autonomous AI agent designed for SRE (Site Reliability Engineering). 

## Tech Stack
- **React**: UI Framework
- **Vite**: Build tool
- **Tailwind CSS**: Styling with neon accents
- **Lucide React**: Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design Philosophy
- **Dark Mode**: Deep `#050505` background for a premium developer feel.
- **Neon Accents**: Using Cyan and Purple to highlight AI-driven capabilities.
- **Glassmorphism**: Subtle borders and transparency for modern card UI.
